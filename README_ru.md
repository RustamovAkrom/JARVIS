Голосовой ИИ-ассистент реального времени, который умеет слышать, видеть, говорить, запоминать и управлять вашим компьютером. ## ⚡ Начните здесь: установка за несколько минут

Нужны Python 3.11+ и ключ Gemini. Сначала получите ключ в
[Google AI Studio](https://aistudio.google.com/apikey), затем выполните:

```powershell
git clone https://github.com/RustamovAkrom/JARVIS.git
cd JARVIS
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Для macOS/Linux после создания окружения используйте
`source .venv/bin/activate` вместо команды `Activate.ps1`.

При первом запуске откроется окно **INITIALISATION REQUIRED**:

1. Вставьте ключ из Google AI Studio в поле **GEMINI API KEY**.
2. Подтвердите определённую автоматически ОС или выберите **Windows**, **macOS**
   либо **Linux**.
3. Нажмите **INITIALISE SYSTEMS**.

JARVIS сохранит ключ и ОС локально в `config/api_keys.json`. Больше ничего для
первого разговора настраивать не нужно. Подробности: [Gemini в JARVIS](/docs/gemini-ru.md).

## ✨ Обзор


JARVIS (v2) создан как практическое расширение вашего компьютера, а не как обычный чат-бот.


Он объединяет голосовое взаимодействие в реальном времени, визуальное восприятие, управление компьютером, постоянную память, фоновые задачи, плагины, мониторинг системы в реальном времени, интерактивный контент, удалённое управление и собственный HUD на PyQt6.


Основное ядро системы отделено от отдельных возможностей. Встроенные действия компьютера автоматически обнаруживаются из `actions/`, а специализированные возможности можно добавлять как отдельные плагины в `plugins/`.


JARVIS может работать с голосом, вводом с клавиатуры, контекстом экрана, веб-камерой, файлами, браузером и удалёнными командами, сохраняя основное взаимодействие внутри одной сессии ассистента.


Это не просто чат-бот — это персональная интеллектуальная система для управления компьютером.

## 🧠 Архитектура


JARVIS (v2) организован вокруг модульного runtime.


### Ядро системы


`main.py` координирует Live-сессию ассистента, ввод/вывод аудио, взаимодействие с Gemini Live, выполнение инструментов, память, плагины, фоновые процессы и интеграцию с UI.


`ui.py` предоставляет PyQt6 HUD, интерфейс аватара, системные панели, поверхности камеры/видео, панели контента, настройки, настройки плагинов, интерфейсы памяти, удалённое управление, представления викторин/анализа документов и callbacks взаимодействия.


Основной runtime и UI намеренно отделены от отдельных возможностей.


### Действия


Встроенные возможности управления компьютером находятся в:


```text

actions/

```


Каждое действие предоставляет словарь `TOOL` на уровне модуля.


Пример:


- [plugins/_template.py](/plugins/_template.py)


Загрузчик действий автоматически обнаруживает корректные файлы действий при запуске.


Добавление нового встроенного действия не требует ручной регистрации в основном runtime.


### Плагины


Дополнительные возможности находятся в:


```text

plugins/

```


Плагин предоставляет определение `PLUGIN` и точку входа runtime:


```python

PLUGIN = {

&#xA0;   "name": "example_plugin",

&#xA0;   "description": "Example JARVIS plugin",

&#xA0;   "parameters": {

&#xA0;       "type": "OBJECT",

&#xA0;       "properties": {}

&#xA0;   },

}


def run(parameters, player=None, session_memory=None):

&#xA0;   return "Done."

```


Плагины are discovered automatically and can optionally provide their own settings schema.


Это позволяет держать специализированную функциональность отдельно от основного runtime.

## ↩️ Отмена действий и безопасность


JARVIS использует два разных механизма для обратимых и необратимых операций.


### Undo


Обратимые операции могут регистрировать обратную операцию.


Примеры:


- перемещение файлов

- переименование

- создание файлов

- копирование

- запись

- организация рабочего стола

- поддерживаемые изменения настроек


Стек отмены является потокобезопасным и хранит ограниченное количество последних операций.


### Confirmation


Необратимые операции используют токен подтверждения, выданный UI.


Модель не может просто передать:


```text

confirmed=yes

```


и выполнить опасную операцию.


Подтверждение должно поступать из пользовательского интерфейса.


Этот механизм предназначен для таких операций, как выключение, перезагрузка, изменение Wi-Fi и другие действительно необратимые или disruptive-операции.

## Дополнительные сведения по установке


```bash

git clone https://github.com/RustamovAkrom/JARVIS.git

cd JARVIS


python -m venv .venv

```


Windows:


```bash

.venv\Scripts\activate

```


Linux/macОС:


```bash

source .venv/bin/activate

```


Установите зависимости проекта:


```bash

pip install -r requirements.txt

```


Запустите JARVIS:


```bash

python main.py

```

При первом запуске откроется окно **INITIALISATION REQUIRED**. В нём:

1. Вставьте ключ из Google AI Studio в поле **GEMINI API KEY**.
2. Проверьте автоматически определённую ОС или выберите **Windows**, **macOS**
   либо **Linux**.
3. Нажмите **INITIALISE SYSTEMS**.

Выбор ОС сохраняется вместе с ключом в локальном `config/api_keys.json` и нужен
JARVIS для платформенных действий. Полная инструкция по ключу, моделям и
безопасности: [Gemini в JARVIS](/docs/gemini-ru.md).

## 🔐 Безопасность


JARVIS построен вокруг local-first управления и чётких границ доступа.


Основные принципы:


- API-ключи хранятся вне исходного кода.

- Конфиденциальная конфигурация не должна попадать в Git.

- Необратимые действия требуют подтверждения через UI.

- Плагины загружаются через контролируемый реестр.

- Загрузчик действий проверяет определения инструментов перед активацией.

- Удалённое управление через Telegram использует allowlist, pairing, rate limiting и ограничения приватных чатов.

- Память хранится локально.

- Специализированные плагины не должны обходить существующую архитектуру actions/plugins.

## 🧩 Расширение JARVIS


Новая встроенная возможность управления компьютером должна находиться в:


```text

actions/

```


Специализированная дополнительная возможность должна находиться в:


```text

plugins/

```


Архитектура плагинов поддерживает:


- автоматическое обнаружение

- объявления инструментов

- схемы параметров

- состояние включения/выключения

- настройки плагинов

- фоновое выполнение

- доступ к player/UI JARVIS

- доступ к памяти сессии

- изолированная обработка ошибок


Это позволяет расширять JARVIS без постоянного изменения центрального runtime.

## 🎯 Направление развития проекта


JARVIS (v2) развивается в направлении более автономного персонального компьютерного ассистента со следующими возможностями:


- более сильный визуальный интеллект

- более широкие возможности управления компьютером

- более глубокая память

- расширенные ОСINT-исследования

- удалённое управление

- интерактивные карты

- больше специализированных плагинов

- проактивная помощь

- улучшенное голосовое взаимодействие в реальном времени

- улучшенная визуализация HUD

- более надёжный fallback моделей

- более сильные механизмы безопасности и подтверждения


Цель — создать модульную систему в стиле JARVIS, которая развивается за счёт независимых действий и плагинов, а не превращается в единое монолитное приложение.
