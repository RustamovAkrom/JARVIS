# JARVIS / MARK LIV

[English](README.md) · [Плагины и разработка](docs/plugins-ru.md) · [Gemini](docs/gemini-ru.md) · [Локальные и сторонние модели](docs/local-llm-ru.md)

JARVIS — настольный голосовой AI-помощник на Python и PyQt6. Он объединяет голосовой диалог, инструменты для работы на компьютере, локальную память и HUD-интерфейс. По умолчанию используется Gemini Live; отдельный режим позволяет собрать голосовой конвейер из выбранных провайдеров, в том числе полностью локальных.

> В текущем коде название сборки — MARK LIV; в интерфейсе и истории проекта также используется JARVIS.

## Возможности

**Голос и диалог:** Gemini Live объединяет микрофон, распознавание речи, голосовые ответы и вызовы инструментов в одной сессии. Есть ввод с клавиатуры и прикрепление файлов. Push-to-talk и локальное ключевое слово «Hey Jarvis» доступны как дополнительные переключаемые функции.

**Работа с компьютером:** встроенные действия из `actions/` открывают приложения и сайты, ищут информацию, обрабатывают файлы, управляют окнами и отдельными настройками ОС, работают с напоминаниями, видео, экраном и камерой. Доступность зависит от ОС, разрешений и установленных программ. Перед необратимыми действиями приложение может запросить подтверждение; некоторые обратимые действия поддерживают отмену.

**HUD и память:** анимированный аватар с синхронизацией речи, показатели CPU/памяти/сети и доступных датчиков, панели диалога, задач, истории, контента и викторин, локальная долговременная память, мини-окно, настройка внешнего вида и командная палитра.

**Интеграции:** дополнительные панели и функции подключаются как плагины. В репозитории есть интеграции для Obsidian, Spotify и Telegram, панели системы/диска/сети/батареи/погоды, а также другие плагины. Они могут требовать ключей, авторизации, внешних приложений или интернет-доступа.

## Установка

Проект требует Python 3.14 или новее. Установка аудио- и мультимедийных библиотек может занять время.

```powershell
git clone https://github.com/RustamovAkrom/JARVIS.git
cd JARVIS
py -3.14 -m venv .venv
.\.venv\Scripts\Activate.ps1
python setup.py
python main.py
```

Если PowerShell запрещает активацию окружения, запускайте `.venv\Scripts\python.exe setup.py`, затем `.venv\Scripts\python.exe main.py`. На macOS/Linux используйте `source .venv/bin/activate`, затем `python setup.py` и `python main.py`. Дополнительные системные зависимости Linux установщик перечисляет в конце.

При первом запуске введите Gemini API key из [Google AI Studio](https://aistudio.google.com/apikey) в окне настройки и подтвердите ОС. Ключ и настройки сохраняются в `config/api_keys.json`. Не публикуйте этот файл и не добавляйте его в Git.

Установщик ставит пакеты из `requirements.txt` и браузеры Playwright Chromium/Firefox. Если браузеры не скачались, установщик выводит команду для повтора; остальная программа может работать без автоматизации браузера.

## Интерфейс и управление

- Центр окна показывает аватар или активный медиаконтент. Слева расположены системные показатели; `L`, `R` и `DOC` скрывают соответствующие панели.
- Справа находятся диалог и задачи. Введите сообщение или используйте микрофон. Файл можно прикрепить и описать требуемое действие.
- **SETUP** (`⚙`) содержит настройку и интеграции. **CONTROLS** (`🎛`) — повседневные переключатели.
- **PLUGINS** включает/выключает плагины; **PLUGIN SETTINGS** настраивает их подключения.
- **ENGINE & PROVIDERS** переключает Gemini Live и альтернативный конвейер STT/LLM/TTS.

Горячие клавиши: `F4` — микрофон, `Escape` — прервать ответ, `F11` — полный экран, `Ctrl+K` — палитра команд, `Ctrl+Shift+Space` — мини-окно. Доступные кнопки и настройки могут немного отличаться в зависимости от ОС.

## Настройки

Предпочитайте UI ручному редактированию JSON: приложение проверяет поля и сохраняет актуальный формат. Большинство настроек находится в `config/api_keys.json`.

В **SETUP** настраиваются ключ Gemini и имя ассистента, тема и цвет HUD, устройства ввода/вывода звука, провайдеры, плагины и поддерживаемые ОС интеграции. В **CONTROLS** — утренний брифинг, wake word, сон/пробуждение, push-to-talk и поведенческие параметры.

Дополнительные ключи конфигурации, распознаваемые текущим кодом: `media_resolution` (`low`, `medium`, `high`, `default`), `thinking_enabled`, `proactive_audio`, объект `turn_tuning`, `plugins_enabled` и `providers`. Точный формат задают `memory/config_manager.py` и `providers/`. Сделайте резервную копию перед ручными изменениями. Пример структуры (не заменяйте им свой файл):

```json
{
  "gemini_api_key": "<ваш ключ>",
  "assistant_name": "JARVIS",
  "plugins_enabled": {"pomodoro": true, "trading_agent": false}
}
```

## Модели и AI

Откройте **SETUP → ENGINE & PROVIDERS**.

### Gemini Live

Режим по умолчанию. Требует Gemini API key и интернет. Модель обрабатывает разговор, аудио и вызовы инструментов в единой сессии. Доступность модели зависит от проекта Google и может меняться.

### MY OWN SETUP: конвейер STT → LLM → TTS

Три отдельные части можно смешивать:

| Часть | Доступные реализации | Примечания |
|---|---|---|
| STT — речь в текст | faster-whisper локально; удалённый OpenAI-compatible endpoint транскрибации | Локальный Whisper по умолчанию использует CPU и модель `base`; загрузка модели происходит при первом использовании. |
| LLM — ответы и инструменты | Ollama, LM Studio, llama.cpp server, vLLM, Jan; OpenAI и OpenAI-compatible сервисы, включая Groq, DeepSeek, Mistral, xAI, OpenRouter, Together, Cerebras | Нужны Base URL, model ID, а иногда ключ. Список моделей может подгружаться с сервера. |
| TTS — текст в речь | Piper локально; голос ОС; ElevenLabs | Piper может загрузить голосовую модель. ElevenLabs требует ключ и интернет. |

Для локального LLM запустите сервер отдельно, выберите соответствующий пункт, проверьте адрес и model ID, нажмите TEST (если доступен), затем **SAVE & APPLY**. Предзаполненные адреса: Ollama `127.0.0.1:11434/v1`, LM Studio `:1234/v1`, llama.cpp `:8080/v1`, vLLM `:8000/v1`, Jan `:1337/v1`.

Для стороннего облачного LLM выберите поставщика, заполните модель, URL и ключ. Произвольный сервис должен быть совместим с OpenAI Chat Completions и используемым форматом tool calling; для закрытого несовместимого API нужен отдельный адаптер.

Можно настроить **sidecar** — отдельную модель для коротких фоновых запросов. Он не заменяет основную модель разговора. Некоторые локальные модели используют сокращённый бюджет инструментов; дополнительные параметры находятся за **MORE**.

Полностью локальный конвейер требует локальных STT, LLM и TTS. Один только локальный LLM не переводит в офлайн-поддержку поиск, облачный STT/TTS, плагины или сетевые действия. Pipeline обычно медленнее Gemini Live; поддержка инструментов зависит от модели и движка. Подробности: [локальные и сторонние модели](docs/local-llm-ru.md), [Gemini](docs/gemini-ru.md).

## Действия и плагины

**Действия** в `actions/` — базовые инструменты компьютера. Они обнаруживаются при запуске; отдельного переключателя для каждого действия в UI нет. Часть функций зависит от ОС.

**Плагины** в `plugins/` — дополнительные инструменты и панели. Их можно выключить и включить обратно через **PLUGINS** без перезапуска. Отключённый плагин не предлагается модели. Файл ненужного плагина можно удалить; некоторые модули используют общий `plugins/_*.py`, поэтому перед удалением проверьте зависимости. Список текущих плагинов, назначение и инструкции: [руководство по плагинам](docs/plugins-ru.md).

В текущем каталоге есть панели батареи, диска, сети, системы и погоды; калорийность по изображению, разбор документов, чат-помощь и OSINT; Excel, игры, Hermes Agent, Obsidian, Spotify, Telegram; Pomodoro, викторины, торговая информация и напоминания о воде. Некоторые требуют внешние аккаунты или ключи. Плагины исполняют доверенный Python-код с правами пользователя — это не песочница.

## Данные и приватность

- `config/api_keys.json` хранит ключи и настройки локально. Считайте его секретным.
- `memory/` хранит долговременную память и состояния функций; `config/` также содержит историю, задачи и напоминания UI.
- Облачный провайдер получает отправленные ему запросы и контекст. Экран, камера, микрофон, файлы и результаты инструментов могут передаваться AI/сервису в зависимости от включённой функции.
- Для локальной обработки проверьте все три слота STT/LLM/TTS и отключите ненужные облачные плагины. Локальная модель сама по себе не гарантирует локальность остальных функций.

## Разработчикам

```text
main.py                  запуск и цикл разговора
ui.py                    PyQt6 HUD, панели и настройки
actions/                 системные инструменты
plugins/                 дополнительные динамические инструменты
core/                    Gemini, аудио, подтверждения, загрузчики и ОС
providers/               контракты STT/LLM/TTS и альтернативный движок
memory/config_manager.py сохранение настроек
dashboard/               веб-панель и HTTP-интеграции
```

Новый плагин — модуль в `plugins/` с декларацией `PLUGIN` (`name`, `description`, `parameters` типа `OBJECT`) и функцией `run(parameters, ...)`. Необязательный `PLUGIN_SETTINGS` создаёт форму в UI; загрузчик передаёт `player` и `session_memory`, только если они объявлены в сигнатуре. Плагины обнаруживаются при старте, а переключение уже загруженного плагина применяется сразу. Добавление файла/изменение кода требует перезапуска. Контракт и примеры — в [руководстве разработчика](docs/plugins-ru.md).

Архитектурные преимущества: разделение UI, инструментов, интеграций и AI-провайдеров; декларативные схемы; настраиваемые плагины; общий событийный контракт альтернативного движка; базовый Gemini-маршрут не зависит от включения `providers/`. Реальная поддержка каждой ОС определяется конкретной функцией.

## Решение проблем

- **Не запускается:** используйте поддерживаемую версию Python и активное `.venv`.
- **Gemini не отвечает:** проверьте ключ, доступ к модели и сеть; включите режим разработки для диагностики.
- **Нет звука:** проверьте разрешения ОС, устройства в **AUDIO DEVICES** и выбранный STT/TTS.
- **Локальный сервер недоступен:** запустите его отдельно, проверьте Base URL, model ID и совместимость API.
- **Плагин BROKEN:** смотрите сообщение в **PLUGINS** — часто отсутствует зависимость, общий helper или авторизация.
- **Не работает браузерная автоматизация:** `python -m playwright install chromium firefox`.

В отчётах об ошибках укажите ОС, Python и шаги воспроизведения. Удалите из журналов ключи, токены, личные данные и содержимое приватных файлов.
