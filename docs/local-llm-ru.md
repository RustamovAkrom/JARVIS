# Локальные и сторонние модели

[English version](local-llm.md) · [Основная документация](../README.md)

Настройте провайдеры в **SETUP → ENGINE & PROVIDERS**, затем нажмите **SAVE & APPLY**. Gemini Live остаётся режимом общения по умолчанию.

## Локальная LLM

1. Установите и запустите сервер модели отдельно: Ollama, LM Studio, llama.cpp server, vLLM или Jan.
2. Загрузите модель и включите API-сервер в соответствующем приложении.
3. В JARVIS выберите **MY OWN SETUP**, затем подходящий пункт LLM.
4. Проверьте Base URL и укажите ID модели. Адреса по умолчанию: Ollama `http://127.0.0.1:11434/v1`, LM Studio `http://127.0.0.1:1234/v1`, llama.cpp `http://127.0.0.1:8080/v1`, vLLM `http://127.0.0.1:8000/v1`, Jan `http://127.0.0.1:1337/v1`.
5. Нажмите TEST, если эта кнопка доступна, затем **SAVE & APPLY**.

Сервер должен поддерживать OpenAI Chat Completions. Вызов инструментов зависит от конкретного сервера и модели. Для некоторых локальных моделей доступны дополнительные настройки с сокращённым набором инструментов.

## Облачные и собственные API

В каталоге есть OpenAI, Groq, DeepSeek, Mistral, xAI, OpenRouter, Together и Cerebras. Укажите endpoint, ID модели и ключ, если он требуется. Собственный endpoint должен поддерживать OpenAI Chat Completions; для несовместимого закрытого API нужен отдельный адаптер. Проверяйте цены и правила обработки данных выбранного провайдера.

## Конвейер STT → LLM → TTS

Три этапа настраиваются независимо и могут сочетать локальные и облачные службы:

- **STT / HEARING:** локальный faster-whisper (`tiny`, `base`, `small`, `medium`, `large-v3`, `large-v3-turbo`; по умолчанию CPU и `base`) или удалённый совместимый endpoint распознавания.
- **LLM / THINKING:** локальная или облачная модель из каталога.
- **TTS / SPEAKING:** локальный Piper (может потребоваться загрузка голоса), голоса операционной системы или ElevenLabs (нужны ключ и интернет).

Для полностью локального конвейера выберите локальную реализацию на всех трёх этапах. Это не делает офлайн поиск, сетевые действия и плагины. Конвейер обычно медленнее Gemini Live, потому что распознавание, генерация и синтез выполняются отдельно. Набор инструментов зависит от движка и модели.

## Sidecar

Дополнительная LLM может обрабатывать короткие фоновые запросы. Настройка **Sidecar first** задаёт, будет ли она предпочтительной для таких задач; основная модель разговора при этом не меняется.

## Решение проблем

- **Connection refused / timeout:** запустите сервер и проверьте API URL.
- **Список моделей пуст:** загрузите модель, проверьте поддержку списка или введите ID вручную, если поле доступно.
- **Плохое распознавание:** проверьте модель STT, язык и микрофон.
- **Нет озвученного ответа:** проверьте TTS, выбранный голос и устройство вывода.
- **Инструмент не вызван:** движок или модель могут не поддерживать вызовы инструментов.
- **Ошибка учётных данных:** проверьте ключ и доступ у провайдера.

Поля провайдеров описаны в `providers/`; настройки хранятся в объекте `providers` файла `config/api_keys.json`. Не публикуйте ключи.
